# Módulo III - Nextflow: Orquestração de workflows e reprodutibilidade

**Nextflow para execução reprodutível de pipelines de Bioinformática**

Este diretório reúne os materiais do módulo de **Nextflow** do **Treinamento de Reprodutibilidade para Análise de Dados (TRAD2026)**. O módulo apresenta os conceitos de gerenciamento de workflows científicos e sua aplicação em ambiente HPC, utilizando **Nextflow**, **SLURM** e **Singularity/Apptainer**, com o pipeline `nf-core/ampliseq`.

---

## Objetivos

Ao final do módulo, espera-se que os participantes sejam capazes de:

- Compreender a lógica de workflows em Nextflow;
- Executar e configurar pipelines;
- Integrar Nextflow, SLURM e containers em ambiente HPC;
- Diagnosticar falhas e retomar execuções;
- Aplicar o Nextflow em uma análise bioinformática real.
